# 👋 Olá, eu sou Felipe Albertim

**Software Engineer I | Backend Java | Microsserviços | Cloud | System Design**

Sou Software Engineer I no **Bradesco**, atuando no desenvolvimento e evolução de soluções para a jornada de **Abertura de Contas**.

Minha atuação é focada principalmente em **Backend e Engenharia de Software**, trabalhando com Java, microsserviços, APIs REST, mensageria, bancos de dados, Cloud e ambientes containerizados.

Também tenho experiência Full Stack, desenvolvendo aplicações com Angular e TypeScript e construindo BFFs para integração entre frontend e backend.

---

## 🧑‍💻 Sobre minha atuação

Atualmente trabalho em um ambiente de sistemas distribuídos e de grande escala, participando da construção, manutenção e evolução de aplicações utilizadas no contexto bancário.

No dia a dia, atuo principalmente com:

- Desenvolvimento de microsserviços utilizando **Java 21**
- APIs **RESTful**
- **Arquitetura Hexagonal**, MVC e princípios **SOLID**
- **Domain-Driven Design (DDD)**
- Comunicação assíncrona utilizando **Apache Kafka**
- Producers, Consumers e **Dead Letter Queues (DLQ)**
- **BFF — Backend for Frontend**
- Desenvolvimento frontend com **Angular e TypeScript**
- **Kubernetes / OpenShift ARO**
- **Azure**
- **MongoDB e SQL Server**
- Observabilidade com **Dynatrace e OpenTelemetry**
- CI/CD utilizando **GitHub Actions**
- Testes automatizados com **JUnit e Jest**
- Qualidade e segurança com **SonarQube e Fortify**
- Code Review e práticas de desenvolvimento colaborativo
